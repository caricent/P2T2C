# 工作区隔离

先检测宿主是否已经提供隔离工作区，并优先使用该机制。使用 `isolation: auto` 时，仅在 R2、并行执行或用户明确要求时创建或请求隔离 worktree；其他情况记录当前分支和干净基线。

执行前检查工作树并运行适用的基线验证。不得覆盖无关的本地改动。只有任务边界独立且文件所有权不重叠的 R2 工作可以并行；每项结果仍必须经过所需审查和批次验证。

工作区隔离只保护实现状态，不能替代 Gate A、Gate B、Truth 审查或危险操作确认。
