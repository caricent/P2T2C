# 迁移 — P2T2C 0.1.0 到 0.2.0

## 摘要

本次迁移引入 AI 可读的安全模板升级机制，以及 Proposal-to-Truth 准入流程。

## 工作流变化

- `READY` proposals use Fast Path and may generate Truth Patch Candidate.
- Non-`READY` proposals use Blocked Path and must write `Truth Patch Candidate: Not generated`.
  - `Supersedes`
  - `Superseded by`
  - `Migration required`

- Change Pack 现在以 Admission Summary 开头。
- `READY` 提案走 Fast Path，并可生成 Truth Patch Candidate。
- 非 `READY` 提案走 Blocked Path，且必须写入 `Truth Patch Candidate: Not generated`。
- Rule block 现在包含生命周期字段：
  - `Supersedes`
  - `Superseded by`
  - `Migration required`

## 升级包变化

- Adds `scripts/p2t2c_upgrade.sh`.

- 增加 `AI_UPGRADE.md`，作为 GitHub-link 升级请求的 AI 入口。
- 增加 `.p2t2c/manifest.yaml`、`.p2t2c/ownership.yaml` 和 lock 元数据。
- 增加 `scripts/p2t2c_upgrade.sh`。
- 增加 dry-run、apply 和 rollback 的 Makefile target。

## 兼容性

- 现有 SP、spec、task 和 Closure Report 保持为历史记录。
- 升级后的新 SP 必须使用升级后的 Change Pack 模板。
- 升级不会修改项目拥有的业务 Truth 和代码。

## 必需验证

```bash
make check
```
