# 规则块写作建议

```text
## RULE-AREA-001：规则名称

Status: Active
Applies to: {适用条件；标题已明确时可省略}
Depends on: {具体规则、定义或例外来源；无则省略}

规则：{主体在什么条件下必须产生什么结果，包含必要边界与例外。}

验证：{可验证的不变量、关键反例或已有验收规范引用。}
```

一条规则表达一个完整主题，沿用稳定唯一 ID。写法不是格式门禁；不强制空栏目、字数或通用停线段落。长期取舍写简短 DEC，历史与实际结果不混入当前规则。不要因为精简而丢失例外，也不要求在每行代码或每个任务添加 Rule ID。
