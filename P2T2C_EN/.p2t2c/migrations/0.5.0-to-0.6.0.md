# 0.5.0 to 0.6.0 Migration

## Summary

This migration reduces the P2T2C project-root surface after installation. The only visible P2T2C directories that users normally work in are:

- `docs/`
- `specs/`

P2T2C internal prompts, templates, scripts, and migration notes move under `.p2t2c/`.

## Path mapping

| Old path | New path |
|---|---|
| `prompts/**` | `.p2t2c/prompts/**` |
| `templates/**` | `.p2t2c/templates/**` |
| `sdd/templates/**` | `.p2t2c/templates/execution/**` |
| `scripts/**` | `.p2t2c/bin/**` |
| `migrations/p2t2c/**` | `.p2t2c/migrations/**` |

## Upgrade rules

- New installs no longer create root-level `prompts/`, `templates/`, `scripts/`, `sdd/`, or `migrations/`.
- Existing projects remove old-path files only when their current hash matches `.p2t2c/lock.sha256`.
- Locally modified old-path files stop the upgrade and produce a conflict report.
- Project-owned `docs/sot/**`, `docs/adr/ADR-*.md`, `docs/change_proposals/CP-*.md`, `docs/closure/CR-*.md`, `specs/**`, code, and tests are not migrated or rewritten.
