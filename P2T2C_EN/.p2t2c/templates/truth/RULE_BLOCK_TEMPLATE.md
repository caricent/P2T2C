# Rule Block Writing Guidance

```text
## RULE-AREA-001: Rule title

Status: Active
Applies to: {Conditions; omit when the title is sufficient}
Depends on: {Specific rule, definition, or exception; omit when absent}

Rule: {Actor, conditions, observable result, and necessary boundaries/exceptions.}

Validation: {Verifiable invariant, key counterexample, or existing acceptance reference.}
```

Express one coherent topic with a stable unique ID. This is guidance, not a style gate: no empty fields, word limit, or generic stop section. Put necessary durable reasoning in short DEC records, not history or actual execution results. Preserve exceptions and do not require Rule IDs on every code line or task.
