# 0.11.0 到 0.12.0 迁移

本次迁移将逐 Task 例外门控流程替换为五阶段风险路由工作流。迁移只更新 P2T2C 工作流外壳，不修改项目拥有的 Truth、ADR、SP、CPK 实例、spec、代码、测试或历史 CR。

## 新工作流

```text
意图准入 -> 风险路由与 Truth -> 工作批次执行 -> 验证与自主修复 -> 漂移检查与收口
```

- 新增 `R0`、`R1`、`R2` 风险等级。
- 新增 `docs/change_packs/` 和持久化 `CPK-*` 契约。
- R1/R2 继续使用 `specs/{feature}/` 精简三件套。
- 所有完成工作都生成 `CR-*`。
- Gate A 只控制尚未决定的 R2 语义；Truth Drift 继续使用 Gate B。
- 首次验证失败允许有界自主修复。

## 退出当前工作流的规则

- `RULE-GOV-010`：代码 `Implements: RULE-*` 锚点。
- `RULE-GOV-011`：逐条 EARS/Task Rule ID 标签。
- `RULE-GOV-012`：阶段 `Phases` 与生成式 phase map。
- `RULE-GOV-013`：single-task Actual、Acceptance scope 和固定 triage 标签。

历史产物继续有效，不要求回填或改写。
