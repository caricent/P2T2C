# Superpowers 方法来源说明

P2T2C 0.13.0 独立实现了五项工作流方法：设计澄清、测试先行、根因调试、独立审查和工作区隔离；其方法灵感来自 [obra/superpowers](https://github.com/obra/superpowers) 公开的方法论与技能。

P2T2C 不要求、不捆绑、也不执行 Superpowers 插件。方法文本由 P2T2C 独立维护，以保持 Truth 边界、风险路由、双语发行契约和安全升级模型。

上游参考版本：`v6.1.1`（审阅日期 2026-07-10）。上游项目以 MIT License 发布。本说明记录方法来源与可追溯性，不增加上游运行时依赖。
