# ADR-013：原生 Truth 治理的执行方法层

Status: Accepted
Date: 2026-07-10

## 背景

P2T2C 已经治理风险路由、Truth、人类关卡、验证和收口。它需要可复用的执行纪律来支持设计澄清、测试先行、调试、审查和安全工作区边界，同时不能创建竞争性的业务规则来源或外部插件依赖。

## 决策

P2T2C 在 `.p2t2c/skills/` 中发布五项原生双语方法。P2T2C 保持控制层地位；方法服从 Truth、来源优先级、R0/R1/R2 路由和 Gate A/B。新安装默认使用 balanced required 配置。既有项目在通过项目配置主动启用前保持 advisory。

## 后果

- 新 R1/R2 模板记录方法检查点，启用方法层的 CR 保留证据。
- required 模式的治理检查仅对已声明方法层的制品强制证据。
- 上游 Superpowers 仅作来源说明，不捆绑也不作为运行时依赖。
- 本决策增加受管工作流资产和升级迁移，但不迁移项目拥有的历史制品。
