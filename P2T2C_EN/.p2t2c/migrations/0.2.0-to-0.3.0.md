# Migration — P2T2C 0.2.0 to 0.3.0

## Summary

This migration simplifies the template by consolidating human and AI entrypoints and removing duplicate navigation documents.

## Workflow Changes

- Human canonical entry is now `README.md`.
- AI canonical entry is now `AGENTS.md`.
- P2T2C governance Truth is consolidated into `docs/sot/governance/P2T2C_GOVERNANCE.md`.
- Core workflow semantics are unchanged:
  - Proposal -> Change Pack -> Gate A -> Truth Patch + Execution Pack -> Coding -> Acceptance -> Closure Report
  - Gate A approves Change Pack application.
  - Gate B resolves Truth Drift only.
  - Change Pack Admission Summary still controls Fast Path vs Blocked Path.

  - Proposal -> Change Pack -> Gate A -> Truth Patch + Execution Pack -> Coding -> Acceptance -> Closure Report
