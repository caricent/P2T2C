# Superpowers Method Attribution

P2T2C 0.13.0 independently implements five workflow methods inspired by the public methodology and skills in [obra/superpowers](https://github.com/obra/superpowers): design refinement, test-first development, root-cause debugging, independent review, and workspace isolation.

P2T2C does not require, bundle, or execute the Superpowers plugin. Its method text is maintained independently so that P2T2C can preserve its Truth boundary, risk routing, bilingual release contract, and safe upgrade model.

Upstream reference version: `v6.1.1` (reviewed 2026-07-10). The upstream project is published under the MIT License. This attribution records inspiration and source provenance; it does not add an upstream runtime dependency.
