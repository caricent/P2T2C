# 0.10.0 到 0.10.1 迁移

本次迁移细化 SP 生成 CPK 后何时需要 Gate A。

## 行为变化

- 如果 SP 不需要变更 SoT 或 ADR，AI 走 Fast Path 并直接生成 CPK。
- 如果 SP 需要变更 SoT 或 ADR，CPK 必须设置 `Gate A required: Yes`，并在应用这些变更前使用明确人类决策选项。
- 只有当 CPK 记录 `Gate A required: No`，且现有 SoT/ADR 已定义所需规则时，执行包生成才可不经过 Gate A。

## 已更新工作流文件

| 文件 | 变更 |
|---|---|
| `P2T2C_AGENTS.md`、`P2T2C_README.md` | 澄清仅 SoT/ADR 变更需要 Gate A。 |
| `docs/submit_proposals/SP_TEMPLATE.md`、`docs/submit_proposals/README.md` | 不需 SoT/ADR 变更的 SP 直接生成 CPK；需要变更的 SP 进入 Gate A 选项。 |
| `.p2t2c/templates/change_packs/CHANGE_PACK_TEMPLATE.md` | 新增两个路由字段，用于判断是否需要 SoT 或 ADR 变更以及是否需要 Gate A。 |
| `.p2t2c/prompts/02_generate_change_pack_prompt.md` | 要求 CPK 判断是否需要 SoT/ADR 变更。 |
| `.p2t2c/prompts/03_apply_change_pack_prompt.md` | 仅 CPK 需要 SoT/ADR 变更且 Gate A 批准时适用。 |
| `.p2t2c/prompts/04_generate_execution_pack_prompt.md` | 允许不需 SoT/ADR 变更的 CPK 不经过 Gate A 直接生成执行文档。 |
| `docs/sot/manifest.yaml`、`.p2t2c/templates/project_config.example.yaml` | 将 Gate A 标签改为应用 SoT/ADR 变更。 |
