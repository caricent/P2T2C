# 迁移 — P2T2C 0.2.0 到 0.3.0

## 摘要

本次迁移通过合并人类和 AI 入口、移除重复导航文档来简化模板。

## 工作流变化

  - Proposal -> Change Pack -> Gate A -> Truth Patch + Execution Pack -> Coding -> Acceptance -> Closure Report
  - Gate A approves Change Pack application.

- 人类权威入口现在是 `README.md`。
- AI 权威入口现在是 `AGENTS.md`。
- P2T2C 治理 Truth 合并到 `docs/sot/governance/P2T2C_GOVERNANCE.md`。
- 核心工作流语义不变：
  - Gate A 批准 Change Pack 应用。
  - Gate B 仅解决 Truth Drift。
  - Change Pack Admission Summary 仍控制 Fast Path 与 Blocked Path。

## 兼容性

- 现有 CP、spec、task 和 Closure Report 保持为历史记录。
- 升级后的新 CP 必须使用简化后的入口模型。
- 升级不会修改项目拥有的业务 Truth 和代码。
