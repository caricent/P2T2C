# Support

Use GitHub issues for bugs, documentation gaps, and workflow questions.

When reporting a problem, include:

- The release root: `P2T2C_EN/` or `P2T2C_CN/`.
- The template version from `P2T2C_TEMPLATE_VERSION`.
- The exact command that failed.
- Relevant output from `make check`, `make checksums`, or `scripts/release_smoke_test.sh`.

Do not include secrets, private source code, or proprietary project Truth.
