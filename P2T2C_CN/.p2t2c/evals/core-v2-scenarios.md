# Core 0.16 按需效果观察

此文件供维护者在实际使用时参考，不是每项任务的检查表或发布所需的固定样本计划。

主要观察：一个人与 AI 协作是否减少打断、重复劳动和返工。优先使用自然发生的真实工作，不额外制造 10–20 个任务、三组对照或全工具资格考试。

| 场景 | 观察重点 |
| --- | --- |
| 明确的小修复 | 按需阅读、最小记录、相关检查后交付，没有重复审批或全量测试 |
| 重要决定或普通失败 | 只询问实际缺失的决定；普通失败由模型自主修复 |
| 缺少必要验收 | 如实说明缺口，不把字段通过当成实际成功 |
| 换会话或整理 SOT | 能继续当前工作，保留适用规则和例外，没有重新填表或全库清理 |

本次新增格式、归档、兼容和内容保护的回归继续使用现有自动化；不把它们追加到消费项目普通任务。声明支持某个项目入口前，验证其实际路径。跨设备、多工具和长期效率统计按需要开展，没有证据不报提速比例。

发现具体失败时先定位信息、工具或规则问题，只补与该失败有关的措施。当前长期效率数据尚未取得，不影响已经满足必要条件的工作交付。
