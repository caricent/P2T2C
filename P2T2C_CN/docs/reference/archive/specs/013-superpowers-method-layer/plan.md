# Plan 013：Superpowers 方法层

Based on: `spec.md`

## 实现策略

新增原生双语方法，并将其检查点接入既有五阶段资产；只在声明方法配置且项目启用 required 时强制执行。

## 影响范围

| 模块或文件 | 动作 | 责任 |
|---|---|---|
| `.p2t2c/skills/**` | 新增五项原生方法技能 | P2T2C |
| Prompt、模板与治理 Truth | 修改 | P2T2C |
| Checker、安装器、升级器与迁移 | 修改 | P2T2C |

## 风险与处理

| 风险 | 处理 |
|---|---|
| 历史制品损坏 | 缺少配置时默认 advisory，只强制已声明配置。 |
| 双语分歧 | 运行发行一致性检查，并保持 shell 脚本完全一致。 |
| 方法层覆盖 Truth | 在治理、入口和每项方法中明确边界。 |

## 验证策略

| 检查 | 命令或步骤 | 覆盖 |
|---|---|---|
| Governance | `make check` | 两个发行根、契约、一致性 |
| 完整性 | `make checksums` 后 `shasum -a 256 -c .p2t2c/CHECKSUMS.sha256` | 受管文件 |
| 交付 | 安装与升级 smoke test | 新项目和既有项目 |

## 隔离、协作与审查

- 隔离与干净基线：宿主管理的工作区，编辑前检查干净 git status。
- 并行所有权边界：不使用；两个发行根作为同步批次修改。
- 独立审查检查点：收口前检查 diff、checker 语义和 smoke-test 输出。
