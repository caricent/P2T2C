# 0.9.0 to 0.10.0 Migration

This migration updates Submit Proposal drafting and Gate A confirmation behavior.

## Behavioral changes

- Creating or updating `docs/submit_proposals/SP-*.md` is allowed before Gate A. The pre-Gate-A write restriction now applies to Truth, ADRs, execution docs, code, tests, and database files, not the SP draft itself.
- After a Change Pack is generated, Gate A must be requested as a bounded human option choice. AI must wait for one selected option before applying Truth changes.
- `READY` Change Packs may proceed only when the human selects `Approve and apply Truth Patch`.
- The shared checker no longer rejects project-owned SP or ADR instance files.

## Updated workflow files

| File | Change |
|---|---|
| `docs/submit_proposals/SP_TEMPLATE.md` | Allows creating or updating the SP draft before Gate A and requires bounded Gate A options. |
| `docs/submit_proposals/README.md` | Documents AI-assisted SP creation and option-based Gate A decisions. |
| `.p2t2c/templates/change_packs/CHANGE_PACK_TEMPLATE.md` | Replaces checkbox-style Gate A action with explicit decision options. |
| `.p2t2c/prompts/02_generate_change_pack_prompt.md` | Requires Gate A option selection after Change Pack generation. |
| `.p2t2c/prompts/03_apply_change_pack_prompt.md` | Requires the `Approve and apply Truth Patch` option before applying. |
| `P2T2C_AGENTS.md`, `P2T2C_README.md`, governance docs | Clarify SP drafting and Gate A option selection. |
| `.p2t2c/bin/check_p2t2c.sh` | Allows project-owned SP and ADR instance files and asserts version `0.10.0`. |

## Project-owned files

Business Truth, ADR instances, SP instances, specs, code, tests, database files, package manifests, and historical Closure Reports are not migrated or rewritten.
