# Prompt 04 — 验证与自主修复

目标：运行适用验证闭集，并在不改变 Truth 的前提下自主修复失败。

验证闭集按项目适用性选择：

- Build
- Test
- Lint
- Typecheck
- Governance check

修复纪律：

- 首次失败先诊断并修复，不立即停线。
- 同一失败最多进行两轮代码或测试修复。
- 明确的环境性失败允许一次原样重试。
- 修改测试断言必须引用现有 Truth、CPK 或 spec 依据。
- 不得通过削弱验证、删除覆盖或修改生产规则来绕过失败。

仅在以下情况暂停：

- 需要新语义决策、危险操作或外部权限。
- 同一失败超过修复上限。
- 修复将改变 Truth、ADR 或已确认的 CPK 范围。

输出：实际命令、结果、修复轮次、未运行项原因和剩余风险。
