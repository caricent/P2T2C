# 0.7.0 到 0.8.0 迁移

## 摘要

本次迁移以三条新治理规则为投射，为 Truth 层增加三项可机器校验的保证。不重命名或删除任何文件，变更为增量式。

- `RULE-GOV-009` — Rule 标识完整性：SoT 规则标识必须唯一，lifecycle 链必须双向，引用必须可解析，被取代的规则不得仍为 `Active`。
- `RULE-GOV-010` — 代码到 Truth 的回链锚点：实现某规则的代码携带仅含指针的 `Implements: RULE-...` 注释；该扫描为软约束，仅在存在 `src/` 树时运行。
- `RULE-GOV-011` — EARS 验收绑定规则标识：每条 EARS 验收语句与每个 task 验收步骤都标注其所验证的规则标识。

## 变更内容

| 区域 | 变更 |
|---|---|
| `docs/sot/governance/P2T2C_GOVERNANCE.md` | 新增 `RULE-GOV-009`、`RULE-GOV-010`、`RULE-GOV-011`。 |
| `.p2t2c/bin/check_p2t2c.sh` | 新增 SoT 完整性扫描与软代码锚点扫描。断言版本 `0.8.0`。 |
| `.p2t2c/templates/truth/RULE_BLOCK_TEMPLATE.md` | 说明仅含指针的代码锚点。 |
| `.p2t2c/templates/execution/spec.md` | EARS 语句末尾带 `[RULE-...]` 标签。 |
| `.p2t2c/templates/execution/tasks.md` | 验收步骤标注其所验证的规则标识。 |
| `.p2t2c/prompts/04_generate_execution_pack_prompt.md` | 要求 EARS 与 task 的标识绑定。 |
| `.p2t2c/VERSION`、`.p2t2c/manifest.yaml` | 版本 `0.8.0`。 |

## 升级规则

- 本次迁移为增量式，不声明任何废弃受管文件。
- 新的 SoT 完整性扫描在每个发行根与每个已安装项目中对 `docs/sot/**` 运行。
- 代码锚点扫描为软约束：不存在 `src/` 树时跳过，因此空模板根与纯文档项目不受影响。
- 已使用唯一标识与双向 lifecycle 链的既有项目 Truth 无需修改即可通过。存在重复标识、悬空引用、或被取代却仍 `Active` 规则的项目，必须先解决才能通过 `make check`。
