# 0.5.0 到 0.6.0 迁移

## 摘要

本次迁移收敛 P2T2C 安装后的项目根目录。使用者日常需要关注的 P2T2C 可见目录只保留：

- `docs/`
- `specs/`

P2T2C 的内部 prompt、模板、脚本和迁移说明移动到 `.p2t2c/` 下。

## 路径映射

| 旧路径 | 新路径 |
|---|---|
| `prompts/**` | `.p2t2c/prompts/**` |
| `templates/**` | `.p2t2c/templates/**` |
| `sdd/templates/**` | `.p2t2c/templates/execution/**` |
| `scripts/**` | `.p2t2c/bin/**` |
| `migrations/p2t2c/**` | `.p2t2c/migrations/**` |

## 升级规则

- 安装新项目时不再创建根级 `prompts/`、`templates/`、`scripts/`、`sdd/` 或 `migrations/`。
- 升级现有项目时，旧路径文件只有在当前 hash 与 `.p2t2c/lock.sha256` 匹配时才会移除。
- 旧路径文件被本地修改时，升级必须停线并生成冲突报告。
- 项目拥有的 `docs/sot/**`、`docs/adr/ADR-*.md`、`docs/change_proposals/CP-*.md`、`docs/closure/CR-*.md`、`specs/**`、代码和测试不迁移、不重写。
