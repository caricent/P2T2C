# 0.8.0 到 0.8.1 迁移

## 摘要

本次迁移消除 `CP` 缩写歧义。此前 `CP` 同时指代 Change Proposal（人类提交的提案）与 Change Pack（AI 生成的候选包），造成混淆。现统一为：

- `SP` = Submit Proposal（人类提交的提案）。
- `CPK` = Change Pack（AI 生成的候选包）。

两者不再共用 `CP` 缩写。本次为命名规范变更，不改变任何工作流语义或关卡逻辑。

## 变更内容

| 区域 | 变更 |
|---|---|
| `docs/change_proposals/` → `docs/submit_proposals/` | 提案目录重命名。 |
| `docs/submit_proposals/CP_TEMPLATE.md` → `docs/submit_proposals/SP_TEMPLATE.md` | 提案模板重命名。 |
| 提案实例命名 `CP-YYYYMMDD-*.md` → `SP-YYYYMMDD-*.md` | 新提案使用 SP 前缀。 |
| `.p2t2c/templates/change_pack/` → `.p2t2c/templates/change_packs/` | Change Pack 模板目录重命名。 |
| `docs/sot/governance/P2T2C_GOVERNANCE.md` | Stage 表为 Change Pack 标注 `CPK` 缩写；阶段说明用 `SP` 指代提案。 |
| `P2T2C_AGENTS.md`、`P2T2C_README.md` | 新增缩写约定说明；目录与工作流引用更新为新名称。 |
| `.p2t2c/ownership.yaml`、`docs/sot/manifest.yaml` | 受管路径与 `proposal_root` 更新为 `docs/submit_proposals`、`SP-*.md`。 |
| `.p2t2c/bin/check_p2t2c.sh`、`p2t2c_install.sh`、`p2t2c_upgrade.sh` | 路径、glob、错误信息更新为 SP/CPK 命名。断言版本 `0.8.1`。 |
| `.p2t2c/VERSION`、`.p2t2c/manifest.yaml` | 版本 `0.8.1`。 |

## 升级规则

- 本次仅为命名规范变更，工作流语义、关卡与停线条件不变。
- 升级脚本将旧的受管模板文件标记为废弃并移除（仅当文件自上次 lock 后未被本地修改）。
- 项目拥有的历史提案实例（旧 `docs/change_proposals/CP-*.md`）不被自动迁移或重命名，仍是有效历史记录。如需统一命名，可在升级后手动将其移动到 `docs/submit_proposals/` 并改用 `SP-` 前缀。
- 升级后新建的提案必须放在 `docs/submit_proposals/` 并使用 `SP-YYYYMMDD-...` 命名。

## 废弃受管文件

升级脚本移除以下未修改的旧受管文件（已被重命名版本取代）：

```text
BEGIN_OBSOLETE_MANAGED
docs/change_proposals/CP_TEMPLATE.md
docs/change_proposals/README.md
.p2t2c/templates/change_pack/CHANGE_PACK_TEMPLATE.md
END_OBSOLETE_MANAGED
```
