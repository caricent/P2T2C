# Specs

Each new change uses exactly `docs/specs/<NNN-short-title>/design.md` and `tasks.md`. Design contains how; tasks track implementation and the completion summary. Completion does not move the directory; it only marks tasks status completed.

A deferred task uses `[-]` and records a stable human-decision reference on the same line, for example `decision: user-20260831-defer-x`; `none`, `pending`, and `unknown` are not evidence.

Historical plan/spec/tasks/work live under `docs/reference/archive/specs/`. They are not converted and are not current authority.
