# 0.9.0 到 0.10.0 迁移

本次迁移更新 Submit Proposal 草拟和 Gate A 确认行为。

## 行为变化

- Gate A 前允许创建或更新 `docs/submit_proposals/SP-*.md`。Gate A 前写入限制现在适用于 Truth、ADR、执行文档、代码、测试和数据库文件，不适用于 SP 草稿本身。
- 生成 Change Pack 后，Gate A 必须以有限人类选项选择的方式请求确认。AI 必须等待人类选择一个选项后，才能应用 Truth 变更。
- `READY` Change Pack 只有在人类选择 `Approve and apply Truth Patch` 后才可继续。
- 共享 checker 不再拒绝项目拥有的 SP 或 ADR 实例文件。

## 已更新工作流文件

| 文件 | 变更 |
|---|---|
| `docs/submit_proposals/SP_TEMPLATE.md` | 允许 Gate A 前创建或更新 SP 草稿，并要求 Gate A 使用有限选项。 |
| `docs/submit_proposals/README.md` | 说明 AI 辅助创建 SP 和基于选项的 Gate A 决策。 |
| `.p2t2c/templates/change_packs/CHANGE_PACK_TEMPLATE.md` | 将 Gate A checkbox 动作改为明确决策选项。 |
| `.p2t2c/prompts/02_generate_change_pack_prompt.md` | 要求 Change Pack 生成后使用 Gate A 选项选择。 |
| `.p2t2c/prompts/03_apply_change_pack_prompt.md` | 应用前要求选择 `Approve and apply Truth Patch`。 |
| `P2T2C_AGENTS.md`、`P2T2C_README.md`、治理文档 | 澄清 SP 草拟与 Gate A 选项选择规则。 |
| `.p2t2c/bin/check_p2t2c.sh` | 允许项目拥有的 SP 和 ADR 实例文件，并断言版本 `0.10.0`。 |

## 项目拥有文件

Business Truth、ADR 实例、SP 实例、spec、代码、测试、数据库文件、package manifest 和历史 Closure Report 不迁移、不重写。
