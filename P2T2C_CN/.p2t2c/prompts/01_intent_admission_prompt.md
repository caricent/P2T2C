# Prompt 01 — 意图准入

目标：确认当前意图足够清晰、与当前 Truth 无冲突，并可进入风险路由。

先读取：

- `P2T2C_AGENTS.md`
- `.p2t2c/project_config.yaml`（如缺失则读示例）
- `docs/sot/manifest.yaml`
- 与当前意图直接相关的 SoT、ADR 和实现证据

输入可以是用户指令、Issue 或可选的 `SP-*`。不要仅为进入流程而强制创建 SP。

动作：

1. 总结目标、非目标和验收结果。
2. 检查歧义、Truth/ADR 冲突和影响范围。
3. 判断是否存在必须由人类选择的产品、架构、安全、权限或数据语义。
4. 清晰且无冲突时直接进入风险路由。

仅在以下情况暂停：

- 意图存在会改变实现结果的关键歧义。
- 与当前 Truth 或已接受 ADR 冲突。
- 继续会发明未决定的业务规则。
- 需要危险操作或外部权限。

输出：准入结论、证据和需要进入阶段 2 的意图摘要。
