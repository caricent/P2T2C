# 0.8.1 to 0.9.0 Migration

## Summary

This migration introduces RULE-GOV-012: **phase-scoped reading and Active/History layering**. The goal is to make the AI's per-task governance reading volume scale with the number of rules relevant to the current phase rather than with the total rule count, controlling the context growth as the workflow iterates over time and rules only accrue.

This is a governance-structure and reading-mechanism change. It does not change any business-rule semantics, gate logic, or stop-the-line conditions.

## Changes

| Area | Change |
|---|---|
| `docs/sot/governance/P2T2C_GOVERNANCE.md` | Each Active rule gains a `Phases` field; per-block lifecycle metadata (`Source`, `Supersedes`, `Superseded by`, `Migration required`, downstream projections) is removed; RULE-GOV-012 is added; the Stop-the-line list is de-duplicated and points to `P2T2C_AGENTS.md` section 4. |
| `docs/sot/governance/P2T2C_GOVERNANCE_HISTORY.md` (new) | Holds the lifecycle metadata for every Active rule, plus the full text of the superseded RULE-GOV-005. Not read by default. |
| `.p2t2c/bin/check_p2t2c.sh` | The RULE-GOV-009 integrity scan now merges the Active + History layers (the same RULE-ID merges fields across files; only an in-file duplicate is an error). Adds the RULE-GOV-012 scan: validates `Phases` tokens and phase coverage, and auto-generates `.p2t2c/generated/phase_rules.txt`. Asserts version `0.9.0`. |
| `.p2t2c/templates/truth/RULE_BLOCK_TEMPLATE.md` | Split into an Active-layer template (with `Phases`) and a History-layer entry, with the allowed phase tokens listed. |
| `docs/sot/manifest.yaml` | Adds the `phases` list, `phase_rule_map`, and `governance_history`; `forbidden_default_reads` includes the History file. |
| `P2T2C_AGENTS.md` | Required Reading switches to reading the governance subset per phase; section 2 stage table gains a `Phase token` column. |
| `.p2t2c/prompts/02..06` | Each stage prompt gains a "Governance reading" note pointing at the matching line of `phase_rule_map`. |
| `.gitignore` (repo root) | Ignores `**/.p2t2c/generated/` (a derived artifact, not part of integrity checks). |
| `.p2t2c/VERSION`, `.p2t2c/manifest.yaml` | Version `0.9.0`. |

## Upgrade Rules

- This is a governance-structure and reading-mechanism change; workflow semantics, gates, and stop-the-line conditions are unchanged.
- `.p2t2c/generated/` is a derived directory rebuilt by `make check`; it is not part of the checksums or lock and is not shipped in the release.
- The upgrade script updates managed files only when the lock hash matches (not locally modified).
- The History file is part of Truth and carries the lifecycle graph; `make check` validates it together with the Active layer.
