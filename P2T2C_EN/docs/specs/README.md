# Specs

The template repository keeps only this README here, without design or task instances. Create a work directory only when a project actually needs standard records.

Only standard uses `docs/specs/<NNN-short-title>/design.md` and `tasks.md`. Design holds necessary implementation choices; tasks hold useful work items and actual completion results. Each checkbox is not a separate approval or full acceptance phase. Compact maintains only its SP, without placeholder specs.

Existing standard retains its identity. Completion does not move the directory; it only marks tasks status completed. Arrange necessary checks around the impact of the deliverable change.

A deferred task uses `[-]` and records a stable human-decision reference on the same line, for example `decision: user-20260831-defer-x`; `none`, `pending`, and `unknown` are not evidence.

Historical plan/spec/tasks/work live under `docs/reference/archive/specs/`. They are not converted and are not current authority.
