# Migration — P2T2C 0.1.0 to 0.2.0

## Summary

This migration introduces AI-readable safe template upgrades and the Proposal-to-Truth Admission flow.

## Workflow Changes

- Change Pack now starts with Admission Summary.
- `READY` proposals use Fast Path and may generate Truth Patch Candidate.
- Non-`READY` proposals use Blocked Path and must write `Truth Patch Candidate: Not generated`.
- Rule blocks now include lifecycle fields:
  - `Supersedes`
  - `Superseded by`
  - `Migration required`

  - `Supersedes`
  - `Superseded by`
  - `Migration required`

## Upgrade Package Changes

- Adds `AI_UPGRADE.md` as the AI entrypoint for GitHub-link upgrade requests.
- Adds `.p2t2c/manifest.yaml`, `.p2t2c/ownership.yaml`, and lock metadata.
- Adds `scripts/p2t2c_upgrade.sh`.
- Adds Makefile targets for dry-run, apply, and rollback.

## Compatibility

- Existing SPs, specs, tasks, and Closure Reports remain historical records.
- New SPs after upgrade must use the upgraded Change Pack template.
- Project-owned business Truth and code are not modified by the upgrade.

## Required Validation

```bash
make check
```
