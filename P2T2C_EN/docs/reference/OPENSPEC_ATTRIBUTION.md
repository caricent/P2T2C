# OpenSpec Attribution

P2T2C 0.15 draws its `Explore -> Propose -> Apply -> Verify -> Archive` action model, the `design.md` / `tasks.md` split, and configurable artifact-dependency idea from [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec). P2T2C retains its own SOT, R0/R1/R2, human decisions, and document layout, with no OpenSpec runtime dependency.
