# Proposals

模板仓库此目录只保留本说明，不预置实际工作记录。项目开始真实工作时再创建 SP；可复用的模板位于 `.p2t2c/templates/core/`。

R1/R2 新工作使用 `SP-YYYYMMDD-short-title.md`，模板位于 `.p2t2c/templates/core/`。standard SP 定义目标、可观察结果、Truth 影响与必要决定；compact SP 同时保存实际结果和必要接续，不另建 design/tasks。

接入支持时由模型为简单明确的 R1 优先选择 compact；其余沿用 standard。R0 不建流程制品，用户要求的报告仍可交付。清晰用户指令不需要重复确认，普通工作不要求用户选模板或填字段。
