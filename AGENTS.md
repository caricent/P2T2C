# AGENTS.md — P2T2C Release Selector

This repository root is not a P2T2C release root.

For English tasks, enter `P2T2C_EN/` and read `P2T2C_EN/P2T2C_AGENTS.md`.

For Chinese tasks, enter `P2T2C_CN/` and read `P2T2C_CN/P2T2C_AGENTS.md`.

Do not treat root-level selector files as project Truth. Current P2T2C workflow Truth lives inside the selected release root under `docs/sot/**`.

Release roots are distributable templates. In this repository, keep `docs/proposals/` and `docs/specs/` README-only; reusable forms belong in `.p2t2c/templates/core/`. Keep repository-maintenance work records outside this template repository. Installed projects create their own work records as needed.
