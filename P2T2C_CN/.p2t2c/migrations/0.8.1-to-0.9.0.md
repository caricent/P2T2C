# 0.8.1 到 0.9.0 迁移

## 摘要

本次迁移引入 RULE-GOV-012：**阶段化按需阅读与 Active/History 分层**，目的是让 AI 每次任务的治理阅读量与当前阶段相关规则数成正比，而非与规则总数成正比，从而在工作流长期迭代、规则只增不减的情况下控制上下文增量。

变更为治理结构与阅读机制调整，不改变任何业务规则语义、关卡逻辑或停线条件。

## 变更内容

| 区域 | 变更 |
|---|---|
| `docs/sot/governance/P2T2C_GOVERNANCE.md` | 每条 Active 规则新增 `Phases` 字段；移除各 Rule Block 的 lifecycle 元数据（`Source`、`Supersedes`、`Superseded by`、`Migration required`、下游投射）；新增 RULE-GOV-012；停线条件清单去重，指向 `P2T2C_AGENTS.md` 第 4 节。 |
| `docs/sot/governance/P2T2C_GOVERNANCE_HISTORY.md`（新增） | 承载所有 Active 规则的 lifecycle 元数据，以及已 `Superseded` 的 RULE-GOV-005 全文。默认不读取。 |
| `.p2t2c/bin/check_p2t2c.sh` | RULE-GOV-009 完整性扫描改为合并 Active + History 两层（同一 RULE-ID 跨文件合并字段，仅在单文件内重复才报错）；新增 RULE-GOV-012 扫描：校验 `Phases` token、阶段覆盖，并自动生成 `.p2t2c/generated/phase_rules.txt`。断言版本 `0.9.0`。 |
| `.p2t2c/templates/truth/RULE_BLOCK_TEMPLATE.md` | 拆分为 Active 层模板（含 `Phases`）与 History 层条目，并列出 allowed phase token。 |
| `docs/sot/manifest.yaml` | 新增 `phases` 列表、`phase_rule_map`、`governance_history`；`forbidden_default_reads` 加入 History 文件。 |
| `P2T2C_AGENTS.md` | 必读顺序改为按 phase 读取治理子集；第 2 节阶段表新增 `Phase token` 列。 |
| `.p2t2c/prompts/02..06` | 每个阶段 prompt 新增"治理阅读"说明，指向 `phase_rule_map` 的对应行。 |
| `.gitignore` | 忽略 `**/.p2t2c/generated/`（派生产物，不纳入校验）。 |
| `.p2t2c/VERSION`、`.p2t2c/manifest.yaml` | 版本 `0.9.0`。 |

## 升级规则

- 本次为治理结构与阅读机制变更，工作流语义、关卡与停线条件不变。
- `.p2t2c/generated/` 为派生目录，由 `make check` 重建，不纳入 checksum 或 lock，不随发行包分发。
- 升级脚本仅在 lock hash 匹配（未被本地修改）时更新受管文件。
- History 文件为 Truth 的一部分，承载 lifecycle 图，`make check` 会连同 Active 层一起校验。
