# Proposals

The template repository keeps only this README here, without actual work records. Create SPs when real project work begins; reusable templates live in `.p2t2c/templates/core/`.

New R1/R2 work uses `SP-YYYYMMDD-short-title.md`; templates live in `.p2t2c/templates/core/`. Standard SP defines goals, observable outcomes, Truth impact, and necessary decisions. Compact SP also holds actual results and useful continuation without separate design/tasks.

The model prefers compact for eligible simple R1 where integration supports it and retains standard otherwise. R0 creates no workflow artifact; requested reports remain deliverables. Clear instructions need no repeated confirmation, template choice, or field entry by the user.
