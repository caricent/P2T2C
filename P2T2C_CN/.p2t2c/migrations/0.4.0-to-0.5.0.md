# 0.4.0 到 0.5.0 迁移

来源：2026-05-19 维护者决策

---

## 摘要

本次迁移将 P2T2C 从一个英文优先、单文件双语发行根改为两个自包含单语发行根。

---

## 新发行根

- `P2T2C_EN/`: English release root.
- `P2T2C_CN/`: Chinese release root.

- `P2T2C_EN/`：英文发行根。
- `P2T2C_CN/`：中文发行根。
- 仓库根目录：仅作为语言选择和聚合检查入口。

---

## 语言策略

- `language_policy: monolingual_release_root`

- `language_policy: monolingual_release_root`
- 受管 docs、prompt、template、README 和迁移说明在各自发行根内保持单语。
- 稳定工作流 token、状态值、文件路径、命令名、CLI 参数和 shell 运行时输出保持英文。

---

## 升级说明

使用目标项目根目录运行升级，并选择目标语言发行根作为 source：

```bash
/path/to/P2T2C_EN/scripts/p2t2c_upgrade.sh --dry-run --source /path/to/P2T2C_EN
/path/to/P2T2C_CN/scripts/p2t2c_upgrade.sh --dry-run --source /path/to/P2T2C_CN
```

审查 dry-run 输出后再应用：

```bash
/path/to/P2T2C_EN/scripts/p2t2c_upgrade.sh --apply --source /path/to/P2T2C_EN
/path/to/P2T2C_CN/scripts/p2t2c_upgrade.sh --apply --source /path/to/P2T2C_CN
```

---

## 兼容性

- 现有 CLI 参数保持不变。
- 脚本运行时输出保持英文。
- 项目拥有的 Truth、ADR、spec、源代码、测试、数据库文件、package manifest 和历史 Closure Report 继续受升级归属规则保护。
