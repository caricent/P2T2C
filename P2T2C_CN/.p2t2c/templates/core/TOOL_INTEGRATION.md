# 工具接入建议

项目入口由项目拥有，安装器不覆盖。保留项目特有的权限、构建和必要验收要求，用简短路由引用 P2T2C_AGENTS.md；不要复制整份治理或每种模型的操作步骤。

可供项目显式采纳的入口说明：

> 当前工作流见 P2T2C_AGENTS.md，当前行为规则只在 docs/sot/**。按目标读取完整适用条款、例外和必要依赖。模型自主选择检索、实现、诊断与检查方法；清晰的已授权范围连续推进，必要项目检查仍有效。新业务语义未决时停止该 change；必要验收未满足不能完成。已有 standard/legacy 保持原身份；项目包装支持时由模型为适用的简单 R1 优先选 compact。检查与影响相称，复用有效结果，正常收口归档一次，不叠加诊断命令。

Codex、Claude Code、Cursor 的项目入口都引用同一权威，不各维护一份规则。定位整篇读取、逐步确认、旧入口及归档包装冲突，在明确的项目变更中修改。新会话验证应观察真实任务路径，而不是只让模型复述规则。
