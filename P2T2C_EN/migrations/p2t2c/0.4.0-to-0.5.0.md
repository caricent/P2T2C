# Migration 0.4.0 to 0.5.0

Status: Active
Source: Maintainer decision on 2026-05-19

---

## Summary

This migration changes P2T2C from one English-first single-file bilingual release root into two self-contained monolingual release roots.

---

## New Release Roots

- `P2T2C_EN/`: English release root.
- `P2T2C_CN/`: Chinese release root.
- Repository root: selector and aggregate check surface only.

---

## Language Policy

- `language_policy: monolingual_release_root`
- Managed docs, prompts, templates, README files, and migration notes are monolingual inside each release root.
- Stable workflow tokens, status values, file paths, command names, CLI flags, and shell runtime output remain English.

- `language_policy: monolingual_release_root`

---

## Upgrade Notes

Upgrade from the target project root using the desired language release as the source:

```bash
/path/to/P2T2C_EN/scripts/p2t2c_upgrade.sh --dry-run --source /path/to/P2T2C_EN
/path/to/P2T2C_CN/scripts/p2t2c_upgrade.sh --dry-run --source /path/to/P2T2C_CN
```

Apply only after reviewing dry-run output:

```bash
/path/to/P2T2C_EN/scripts/p2t2c_upgrade.sh --apply --source /path/to/P2T2C_EN
/path/to/P2T2C_CN/scripts/p2t2c_upgrade.sh --apply --source /path/to/P2T2C_CN
```

---

## Compatibility

- Existing CLI flags are unchanged.
- Script runtime output remains English.
- Project-owned Truth, ADRs, specs, source code, tests, database files, package manifests, and historical Closure Reports remain protected by upgrade ownership rules.
