# 迁移 — P2T2C 0.3.0 到 0.4.0

## 摘要

本次迁移将受管 P2T2C 模板改为英文优先、单文件双语，以便全球开发者采用。

## 工作流变化

  - Proposal -> Change Pack -> Gate A -> Truth Patch + Execution Pack -> Coding -> Acceptance -> Closure Report
  - Gate A approves Change Pack application.
  - Gate B resolves Truth Drift only.
  - `language: en-US`
  - `supported_languages: [en-US, zh-CN]`
  - `language_policy: english_first_single_file_bilingual`

- 核心工作流语义不变：
  - Gate A 批准 Change Pack 应用。
  - Gate B 仅解决 Truth Drift。
  - Change Pack Admission Summary 仍控制 Fast Path 与 Blocked Path。
`Workflow CN` 改为英文优先双语：
  - `language: en-US`
  - `supported_languages: [en-US, zh-CN]`
  - `language_policy: english_first_single_file_bilingual`
- 受管 docs、prompts、templates、README 文件和迁移说明现在在同一文件中英文优先并提供中文等价说明。
- shell 脚本运行时输出保持英文。

## 升级包变化

- Updates `P2T2C_TEMPLATE_VERSION` to `0.4.0`.
- Regenerates `CHECKSUMS.sha256` and `.p2t2c/lock.sha256`.

- 将 `P2T2C_TEMPLATE_VERSION` 更新为 `0.4.0`。
- 更新 `.p2t2c/manifest.yaml`、`docs/sot/manifest.yaml` 和 `project_config.example.yaml` 语言元数据。
- 原地更新受管文档和模板内容。
- 将本迁移说明加入受管迁移列表。
- 重新生成 `CHECKSUMS.sha256` 和 `.p2t2c/lock.sha256`。

## 兼容性

- 现有 SP、spec、task 和 Closure Report 保持为历史记录。
- 升级后的新 SP 应使用英文优先双语模板。
- 升级不会修改项目拥有的业务 Truth、ADR、spec、代码、测试、数据库文件、package manifest 或历史 Closure Report。
- CLI 参数、Makefile target、安装行为、升级行为和回滚行为均不变。

## 必需验证

```bash
make check
shasum -a 256 -c CHECKSUMS.sha256
```

建议烟测：

```bash
make p2t2c-install-dry-run TARGET=/private/tmp/p2t2c-install-smoke
make p2t2c-install TARGET=/private/tmp/p2t2c-install-smoke
cd /private/tmp/p2t2c-install-smoke
make check
/path/to/p2t2c-release/scripts/p2t2c_upgrade.sh --dry-run --source /path/to/p2t2c-release
```
